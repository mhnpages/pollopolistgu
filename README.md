# Pollopolis · Menú digital

Website: https://mhnpages.github.io/pollopolistgu/

Menú interactivo de Pollopolis con fotografías, precios en lempiras, categorías, paquetes de 30 y 50 piezas, sucursales y acceso a PedidosYa Las Uvas.

## Publicación

GitHub Pages publica la rama `main` desde la raíz `/`. El archivo `.nojekyll` permite servir los archivos estáticos directamente. No requiere instalar dependencias.

El sitio incluye `index.html`, sus estilos, imágenes, datos y `app-standalone.js`. Conserva estos archivos juntos para abrir también el menú directamente desde el disco.

Precios y fotografías proporcionados y aprobados por Pollopolis. Los precios pueden variar en PedidosYa. Disponibilidad según sucursal.
